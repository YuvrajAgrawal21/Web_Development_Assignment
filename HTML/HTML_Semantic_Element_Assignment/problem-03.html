Appointment Steps

  1. Select a department.
  2. Select a doctor.
  3. Select a date and time.
  4. Fill the appointment form.
  5. Wait for confirmation.

Medical Terms

Consultation
Discussion with a healthcare professional.
Follow-up
A later visit after an earlier consultation.
OPD
Outpatient Department.
Appointment
A fixed time for meeting a doctor.
